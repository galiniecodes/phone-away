Source URLs, sizes, SHA-256 hashes, export package versions, and exact export
options for these assets are pinned in scripts/realtime-assets.json.
Verify offline with: python3 scripts/download_realtime_models.py --verify
Restore runtime files with: python3 scripts/download_realtime_models.py
To rebuild a missing ONNX model, create a Python 3.12 virtual environment
under work/, install scripts/realtime-export-requirements.txt into it, and
run the restore command with --export-python PATH/TO/VENV/bin/python.
The exporter downloads no training data, performs no training, checks the
official checkpoint checksum, and verifies the exported model checksum.
Python ML dependencies are build-only; running the app does not need them.

Detection limitations
  YOLO26n predicts object categories and bounding boxes. MediaPipe predicts
  hand landmarks. Phone Away combines their positions to estimate whether
  a visible phone is in a hand. These pretrained models do not determine
  attention, intent, productivity, or whether a person is working. Small or
  partially hidden phones, occluded hands, unusual angles, poor lighting,
  and hands resting beside a phone can cause misses or false positives.
  The yellow box shows a detected phone; holding is a separate heuristic.
  Local inference uses only same-origin files and never sends camera frames
  to a third party. Setup scripts only download runtime/model files.
